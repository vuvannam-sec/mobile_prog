# Personal Finance Manager

A mobile application for personal finance management, developed as part of a Mobile Programming course project.

## Overview

This Android application helps users take control of their finances by providing intuitive tools to track expenses, manage budgets, and monitor income streams.

## Features

- **Expense Tracking**: Record and categorize daily transactions
- **Budget Management**: Set spending limits and track progress
- **Income Monitoring**: View and analyze income sources
- **Financial Reports**: Visualize spending patterns and trends

## Tech Stack

- **Language**: Kotlin
- **Platform**: Android
- **Build Tool**: Gradle
